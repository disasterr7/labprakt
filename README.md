## 1. Тема и основной пользовательский сценарий

- **Тема проекта**: Каталог фильмов и сериалов — просмотр, оценки и избранное.
- **Целевой пользователь**: Любитель кинематографа, желающий упорядочить свои просмотры и находить новое кино.
- **Основной сценарий**: Приложение помогает пользователю вести персональную медиатеку. Пользователь может просматривать каталог кинокартин и сериалов, фильтровать их по статусу («В планах», «Смотрю», «Просмотрено»), открывать подробную карточку конкретного фильма, создавать новые записи через валидируемую форму, редактировать существующие данные и удалять фильмы с подтверждением.

## 4. Маршруты приложения (ЛР 2 и ЛР 3)

В проекте настроена клиентская навигация SPA (Single Page Application) без перезагрузки страниц:

| Маршрут | Описание | Компонент |
| :--- | :--- | :--- |
| `/` | Перенаправление на каталог | `<Navigate to="/movies" replace />` |
| `/movies` | Список фильмов с фильтрацией по статусу просмотра | `<MoviesPage />` |
| `/movies/:id` | Подробная карточка фильма по ID с кнопками редактирования и удаления | `<MovieDetailsPage />` |
| `/movies/new` | Экран создания новой картины с валидируемой формой | `<NewMoviePage />` |
| `/movies/:id/edit` | Экран редактирования картины с предзаполненной формой | `<EditMoviePage />` |
| `/movies/missing` | Обработка отсутствующей записи по ID | `<MovieDetailsPage />` (сообщение «Фильм не найден») |
| `*` (любой другой) | Страница ошибки 404 (неизвестный адрес) | `<NotFoundPage />` |

*Все страницы отображаются внутри общего макета `<AppLayout />` со сквозной шапкой, навигацией и уведомлением о хранении данных в памяти.*

## 5. Инструкция по установке и запуску

Все команды выполняются из терминала.

### 5.1. Запуск в режиме разработки (Dev)

Из корня репозитория:
```bash
cd frontend
npm ci
npm run dev
```
После запуска откройте в браузере локальный адрес (по умолчанию: `http://localhost:5173`).

### 5.2. Проверка сборки (Production Build) и предпросмотр (Preview)

Перед фиксацией изменений или сдачей работы проверьте строгую компиляцию типов и сборку:
```bash
cd frontend
npm run build
npm run preview
```
Команда `npm run build` выполняет проверку типов TypeScript (`tsc -b`) и оптимизированную сборку в каталог `frontend/dist`.  
Команда `npm run preview` запускает локальный статический сервер для просмотра готовой сборки.
