## 1. Тема и основной пользовательский сценарий

- **Тема проекта**: Каталог фильмов и сериалов — просмотр, оценки и избранное.
- **Целевой пользователь**: Любитель кинематографа, желающий упорядочить свои просмотры и находить новое кино.
- **Основной сценарий**: Приложение помогает пользователю вести персональную медиатеку. Пользователь может просматривать каталог кинокартин и сериалов, выставлять личные рейтинги (оценки), формировать список «Избранное» и «Посмотреть позже», а также быстро находить нужные ленты с помощью фильтрации по жанрам и годам.

## 4. Инструкция по установке и запуску

Все команды выполняются из терминала.

### 4.1. Запуск в режиме разработки (Dev)

Из корня репозитория:
```bash
cd frontend
npm ci
npm run dev
```
После запуска откройте в браузере локальный адрес (по умолчанию: `http://localhost:5173`). Сервер Vite автоматически отслеживает изменения в коде (Hot Module Replacement) и моментально обновляет интерфейс.

### 4.2. Проверка сборки (Production Build) и предпросмотр (Preview)

Перед фиксацией изменений или сдачей работы проверьте строгую компиляцию типов и сборку:
```bash
cd frontend
npm run build
npm run preview
```
Команда `npm run build` выполняет проверку типов TypeScript (`tsc -b`) и оптимизированную сборку в каталог `frontend/dist`.  
Команда `npm run preview` запускает локальный статический сервер для просмотра готовой сборки.
