## Лабораторная работа №2: Страницы приложения и навигация

### 1. Результат лабораторной работы
- Установлен и подключен пакет `react-router` (декларативная маршрутизация SPA).
- Описан интерфейс модели `Movie` в `frontend/src/types/movie.ts` (10 полей: `id`, `title`, `originalTitle`, `description`, `type`, `genre`, `releaseYear`, `rating`, `status`, `durationOrEpisodes`).
- Создан демонстрационный массив из 6 кинокартин и сериалов в `frontend/src/data/movies.ts` с уникальными id и разнообразными статусами.
- Разработан переиспользуемый компонент карточки `MovieCard` с типизированными props и понятными русскоязычными бейджами статусов.
- Реализован общий макет `AppLayout` со сквозной шапкой, навигацией `<NavLink to="..." end>` и элементом `<Outlet />`.
- Созданы 4 страницы:
  - `MoviesPage` — список карточек, отображение пустого состояния, кнопка перехода к созданию;
  - `MovieDetailsPage` — чтение `:id` из URL через `useParams`, вывод всех деталей фильма;
  - `NewMoviePage` — заглушка экрана добавления с пояснением, что форма появится в ЛР 3;
  - `NotFoundPage` — обработка неизвестных маршрутов (ошибка 404).
- Раздельно обрабатываются ситуации отсутствия данных:
  - неизвестный адрес (`/unknown`) -> страница 404 (`NotFoundPage`);
  - отсутствующий id фильма (`/movies/missing`) -> сообщение «Фильм или сериал не найден» внутри `MovieDetailsPage`.
- Добавлены адаптивные стили (CSS Grid, перенос ссылок на ширине 360px без горизонтального скролла, выделение активного пункта навигации, видимый фокус с клавиатуры `Tab`).
- Проект успешно собирается `npm run build` с нулевым количеством ошибок.

### 2. Шаги проверки приложения (Чек-лист методички)
1. Открытие `/` — происходит редирект на `/movies`, отображается список из 6 карточек.
2. Открытие двух разных карточек (`/movies/m1` и `/movies/m2`) — отображаются разные данные.
3. Прямое открытие карточки по URL в новой вкладке и обновление страницы — карточка открывается стабильно.
4. Переход к созданию (`/movies/new`) — отображается заглушка и общее меню.
5. Открытие `/unknown` — отображается 404 `NotFoundPage`.
6. Открытие `/movies/missing` — отображается отдельное сообщение «Фильм или сериал не найден».
7. Проверка пустого списка (при очистке массива выводится блок «Фильмов и сериалов пока нет в каталоге»).
8. Проверка навигации с клавиатуры (клавиша `Tab` для фокуса, `Enter` для перехода) и мобильной ширины 360px.
9. Проверка SPA-переходов: в консоли вкладки Network при переходах по ссылкам нет повторной загрузки всего HTML-документа.
10. Проверка сборки `npm run build` и предпросмотра `npm run preview`.
